# PRD Template — Section Definitions

Used in the prd_drafter.py prompt to instruct Claude on each field.

## problem
One paragraph. What is broken, painful, or missing? Who feels the pain? What is the current workaround (if any)?

## personas
List the people who interact with this feature. Format: "Name — role description". Keep to 1-3.

## features
Bullet list of what the feature does. Each bullet is one observable capability. No implementation detail.

## success_metrics
Bullet list of measurable outcomes. At least one must be objectively verifiable (e.g. file count, latency, user action count).

## out_of_scope
Bullet list of what this version explicitly does NOT cover. Prevents scope creep.
